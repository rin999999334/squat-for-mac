# Squat for Mac 0.9.2 — Public Preview

AIを使う時間に、小さな運動のきっかけを。

- Homeで利用時間・運動記録を確認し、目標1〜30回でGo Squat。
- カメラで上下の動きをカウント。映像は保存・送信しません。
- Mac版ChatGPT/Codex・Claudeの利用時間に応じて運動を通知。
- メニューバーでアプリ別の時間と次の通知までを確認。
- 日本語・英語に対応。

[初回起動の手順](https://github.com/rin999999334/squat-for-mac/blob/main/docs/DOWNLOAD.md) · [既知の制限](https://github.com/rin999999334/squat-for-mac/blob/main/docs/KNOWN_ISSUES.md) · [プライバシー](https://github.com/rin999999334/squat-for-mac/blob/main/PRIVACY.md)

## Download

Apple Silicon向けの **Squat-for-Mac-0.9.2-arm64.zip** をAssetsからダウンロードしてください。Source codeのZIPはアプリではありません。GitHubへのログインは不要です。

Developer ID署名・Apple公証は未対応です。初回はmacOSの警告が表示される場合があります。入手元を確認し、[Appleの公式手順](https://support.apple.com/ja-jp/102445)に従ってアプリ単位で判断してください。Mac全体の保護を無効にする必要はありません。

## Changes since 0.9.1

共有の初期URLを実際の公開リポジトリへ変更しました。旧デモURLだけを置き換え、独自に設定したURLと既存の記録・保存先は保持します。

## Limits

利用時間による通知が対象です。通常のChatGPT/Claudeの送信・回答完了検知と任意のプラグイン連携は、このプレビューでは対応機能に含めません。Intel・最低対象OS全体の実機確認は未完了です。ソースコードの利用・改変・再配布ライセンスは未決定です。

以前の同じMacで使った記録は再ダウンロードしても残ります。配布ファイル自体に個人の記録は含めていません。
