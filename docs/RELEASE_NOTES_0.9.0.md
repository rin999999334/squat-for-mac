# Squat for Mac 0.9.0 — private preview

This is a private pre-release for review. It is not an Apple-notarized public distribution.

- New app name and the owner-provided blue Squat icon.
- Separate daily ChatGPT/Codex and Claude durations in the menu bar.
- Remaining active AI time shown with seconds and refreshed while the menu stays open.
- Removed “Pause reminders today,” including its legacy effect, while retaining records.
- Japanese and English guides, demo screenshots, privacy explanations and release checks.

Use **time-based reminders** for daily use. Send-triggered integration remains experimental and has a known production/review receiver mismatch. Ordinary ChatGPT/Claude send detection and response completion are not established. X/Instagram images require manual attachment.

The ZIP contains the generic application, with no personal profile, records or preferences. It is locally ad hoc signed. Read the user guide before opening a downloaded build; do not disable system protections.

Outstanding public-release gates include Developer ID signing and notarization, license selection, supported-hardware acceptance, companion helper provenance, and the integration/quit checks listed in `docs/KNOWN_ISSUES.md`.
