# Squat for Mac 0.9.1 — private preview

- Unified the source folder, executable, package and build-input names as SquatForMac. User-visible branding remains Squat for Mac.
- Kept storage identifiers and data compatibility unchanged. Existing records are not bundled in the download.
- The native preview is now built as dist/Squat for Mac Preview.app with its existing isolated preview identifier.
- Added download-first instructions and a local cleanup inventory. No old files or records were deleted.

This is an Apple Silicon private pre-release, ad hoc signed and not Apple-notarized. Time-based reminders remain the supported daily-use mode. Plugin receiver integration and the public-release gates in docs/KNOWN_ISSUES.md remain unresolved. The 0.9.0 security source review is historical evidence, not a new full audit of this revision.
