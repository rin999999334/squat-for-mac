# ダウンロードして初めて開く

対象：Squat for Mac 0.9.3、Apple Silicon。GitHubからログインなしでダウンロードできます。

1. [0.9.3のリリース](https://github.com/rin999999334/squat-for-mac/releases/tag/v0.9.3)を開き、Assetsの **Squat-for-Mac-0.9.3-arm64.zip** をダウンロードします。Source codeのZIPはアプリではありません。
2. ダウンロードしたZIPをダブルクリックして展開し、表示された **Squat for Mac.app** を開きます。
3. 公証前のためmacOSに止められる場合があります。入手元・対象アプリを確認したうえで、[Appleの案内](https://support.apple.com/ja-jp/102445)に従い、システム設定 → プライバシーとセキュリティ → 該当アプリの「このまま開く」で判断します。「悪質」「破損」など別の警告なら、そのまま無視して進めず内容を確認します。保護機能の一括無効化は行いません。
4. 確認画面で、初回は「インストール」、旧版がある場合は「置き換える」を押します。アプリがApplicationsへコピーされ、インストール済みの版が開きます。新版のダウンロードや置換を勝手に行う機能ではありません。
5. 書き込み権限などで自動処理できない場合は旧版を変更せず、手動移動の案内を表示します。その場合だけ旧版をメニューバーから終了し、新版をFinderで「アプリケーション」へ移動してください。
6. Homeから設定を開き、AI Apps、通知ON、間隔、日本語／英語を確認します。通知は前面でのAI利用時間を基準にし、追加のプラグインは使いません。
7. Go Squatを押すと、必要な場合にカメラの許可が出ます。上半身が映る位置まで離れ、位置合わせを待ちます。

## 既存の記録と「まっさら」の違い

配布ZIPに個人の記録・設定・互換プロファイルは入っていません。記録と設定はアプリ本体とは別に保存されるため、同じmacOSユーザーの旧版を置き換えても残ります。旧確認版が個別の保存プロファイルを使っている場合は、0.9.3への初回置換時にその識別子だけをmacOS環境設定へ移し、同じ保存先を参照します。

同じmacOSユーザーには以前の標準版の設定・カメラ許可が残る場合があるため、ZIPを再ダウンロードするだけでは完全な初回状態を保証しません。権限ダイアログを含めて初回体験を確認する場合は、別のmacOSユーザーまたはテスト用Macで行います。

手動で複数のコピーを残した場合は同時起動せず、Applications内の新版を使ってください。

## デザイン用プレビュー

現行リポジトリで次を実行します。

```sh
./scripts/preview.sh
open "dist/Squat for Mac Preview.app"
```

通常版とは別のbundle ID・設定・一時DBを使うデモです。画面に見える架空の記録を本番へ保存しません。通常版のアプリ名はSquat for Mac、プレビューはSquat for Mac Previewです。
