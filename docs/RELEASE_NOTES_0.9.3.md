# Squat for Mac 0.9.3

Apple Silicon向け公開プレビュー版です。

## 変更

- GitHub Releasesからダウンロードした新版を開き、確認画面の「置き換える」を押すと、Applicationsの旧版を安全に差し替えて新版を開けるようにしました。
- 運動記録と設定はアプリ本体とは別に保持します。旧確認版が個別の保存プロファイルを使っている場合も、その識別子を安全に移して同じ記録を引き継ぎます。
- 採用しないAI送信プラグインと関連画面・同梱物を削除しました。通知は前面でのAI利用時間を基準にします。
- 未実装だった通知音の設定、音声素材、再生処理を削除しました。

## 既知の制限

- Developer ID署名とApple公証は未対応です。初回起動は[手順](DOWNLOAD.md)を確認してください。
- Applicationsの0.9.1から0.9.3への終了・置換・署名検証・新版起動・記録保持は同一Macで確認済みです。別Mac、書き込み権限がない場合、Intel Macは未確認です。
- AIの回答生成・送信完了は検知しません。選択したMac版AIアプリの前面利用時間を基準に通知します。
