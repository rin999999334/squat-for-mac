# Squat for Mac — 使い方・FAQ

対象：0.9.0 非公開確認版。現在はApple Siliconでのローカル利用を確認する段階です。通常利用には通知タイミングの「利用時間」を選んでください。

## Install and open

手元でビルドする場合は、リポジトリのルートで次を実行します。

```sh
./scripts/build.sh
open "dist/Squat for Mac.app"
```

生成されるアプリを普段使う場所に置き、同じ名前の古いアプリと同時に起動しないようにしてください。個人用に配置したアプリには記録の互換プロファイルが設定されている場合があります。配布用の新規ビルドには個人の記録を含めません。

この段階ではDeveloper ID署名・Appleの公証はありません。ダウンロード由来のアプリはMacに止められる場合があります。出所を確認し、[Appleの安全な開き方](https://support.apple.com/ja-jp/102445)に従ってください。本人が内容と出所を確認して許可する場合の例外は、システム設定 → プライバシーとセキュリティ → 該当アプリの「このまま開く」です。Mac全体の保護を無効にしたり、警告の内容を確認せず開いたりしないでください。

## 初めに設定するもの

1. メニューバーのSquatを開き、アプリを表示します。
2. 設定の **AI Apps** でChatGPT/Codex・Claudeを選びます。
3. 通知をONにして、30・60・90・120・180分から間隔を選びます。
4. 通知タイミングは **利用時間** にします。任意のプラグイン連携はまだ日常利用の前提にできません。
5. 効果音を使う場合は音量を上げます。0では音が鳴りません。
6. 必要に応じて日本語・英語と、**PC利用時間 / Desk time** のON/OFFを選びます。

新規インストールでは、AIアプリの選択・時間の集計・通知が有効とは限りません。既存設定を引き継いだ個人用アプリでは、前の値が残ります。設定を確認してから使ってください。

## AI利用時間とメニューバー

認識するのはMac版ChatGPT (`com.openai.chat`)、Codex (`com.openai.codex`)、Claude (`com.anthropic.claudefordesktop`)です。ブラウザ版や、ターミナル内のCLIはAI利用として計測しません。

両方のアプリを開いていても、操作対象である前面のアプリだけを数えます。ChatGPTを10分、Claudeを20分使えば、通知の判定では約30分です。ChatGPTとCodexは共通の項目です。画面の左右に並べていても二重には数えません。

メニューバーでは今日の各アプリの時間を秒まで、別々に表示します。`--h--m--s`は、その日の計測データがない状態です。計測済みの0秒とは区別します。

「次の通知まで（AI利用）」は**対象AIアプリを前面で使う必要がある残り時間**です。通常の時計のタイマーではありません。別アプリを使っている間は減りません。5分以上操作がない・Macがスリープ中・ロック中・カメラで運動中などは計測を止めます。状態の説明もメニューに表示します。

Desk timeは対象AIに限らない、有効なPC利用時間です。設定のAI Appsと通知の間に切替があります。AI利用を含むので、AI時間と足して総利用時間にするものではありません。Desk time自体からは通知しません。OFFにしても過去に記録した時間は消しません。

## 通知の流れ

- 設定したAI利用時間に達すると、通常の通知を約8秒表示します。
- 通知を押すとアプリを開き、カメラの許可と開始へ進みます。
- 運動しなかった場合は、次の通常の間隔、または最初の通知から45分後の早い方で、カウントダウン通知を1回待機します。
- 30分設定なら約30分の追加AI利用で先に再通知できます。60分設定なら、45分後が先に来る場合があります。
- 再通知も、対象AIアプリが前面で操作できる状態になるまで待ちます。別アプリの操作中やスリープ中に強制表示しません。
- カウントダウンは最初から10秒表示です。0を約0.4秒保持してから約0.24秒で消え、0でカメラが自動起動することはありません。

通知後の「次の通知まで」の数値は、次の通常のAI利用間隔です。45分後の再通知については状態の説明で示します。日付変更や通知条件の変更、終了をまたいで再通知をそのまま再生することはありません。新たな利用で通常の通知周期は続きます。

1回以上の実際の動きが保存され、その運動を終えると、通知用の進み具合と再通知の待機をリセットします。当日の利用時間や運動記録は残ります。

## カメラで運動する

1. Homeで今回の目安となる目標回数を1〜30から選び、**Go Squat** を押します。
2. 初回はカメラの許可を求められます。通常利用にアクセシビリティや画面収録の許可は不要です。
3. 上半身が見える程度まで離れ、安定した位置で約3秒待ちます。実際の位置合わせは顔の検出を使います。
4. Startから下がり、Endを越え、Start側へ戻ると1回です。Challengeはさらに深く動く目安で、追加点は付きません。
5. 左下のHomeで運動を終えて戻ります。位置がずれた場合は隣の再調整を押し、約3秒待ちます。既に数えた回数は残ります。
6. 右下の−／＋は今回の目標を変更します。上限は30です。既に達成した回数より低い目標にはしません。

目標に届くとカメラを止めて結果を表示します。途中でHomeに戻っても、保存に成功した1回以上の運動はその日の実績として残り、週間のチェックにも反映します。記録の保存に失敗した表示がある場合は、画面の案内に従って再試行してください。

このカウンターは顔位置の上下動を利用します。正しいフォーム・膝の角度・運動の安全性を保証するものではありません。顔が画面から外れる、複数人が映る、逆光が強い、カメラ位置が変わる場合は数えられないことがあります。無理のない範囲で使ってください。

## Detailと共有

Homeの`days`は、実際に運動した日付の累計です。連続日数やインストールからの経過日数ではありません。

Detailでは日付に合わせた数値とカレンダーを確認できます。画面のTotalは表示期間の合計です。**共有するTotalカードは全期間の合計**で、経過日数は初回の実施日から今日まで（初日は0日）、最長連続は全記録の最長日数です。

共有画面の画像を確認し、次のいずれかを選びます。

- **Save**：PNGを保存します。
- **Copy image**：画像をクリップボードに入れます。
- **X**：画像を保存し、開いたXの投稿欄で自分で添付します。指定したGitHub URLが投稿欄に入ります。
- **Instagram**：保存画像を自分で選び、必要ならコピーしたURLを貼ります。
- **More…**：macOSの共有先を選びます。画像とGitHub URLをその共有サービスへ渡します。

X・Instagramへの自動画像添付・自動投稿はありません。Todayの共有画像にはカード内の共有ボタンを含めません。GitHub URLは共有画面のEditから変更できます。未設定時は明示したデモURLなので、公開前に変更してください。非公開リポジトリのURLは、権限のない人には開けません。

## FAQ

**閉じるボタンを押すと終了しますか？** いいえ。ウィンドウを閉じてもメニューバーに残り、条件が合えば計測します。メニューのQuitで終了すると計測も通知も止まります。

**起動していない間の時間も計測できますか？** できません。後から取り戻して集計することはありません。ログイン時の自動起動も登録しません。

**次の通知までが減らないのはなぜ？** 対象AIが選ばれているか、集計と通知がONか、通知方式が利用時間かを確認してください。別アプリを前面にしている・5分以上操作がない・ロックやスリープ中・運動中などでは止まります。残り0でも、通知可能な画面や記録の保存状態になるまで表示を待つことがあります。

**AIが裏で回答を生成している間は？** 前面アプリを基準にします。背面での生成時間や送信・生成の成否は判定しません。返信内容を読みません。

**プラグインを入れれば通常のChatGPTやClaudeの送信で動きますか？** 現状そうは言えません。Codex用の任意のローカルフックは実験段階で、同梱ヘルパーが確認版の接続先を指す不一致も残ります。通常ChatGPT/Claudeの送信・回答完了は対応していません。「接続を確認」は待受を始める操作で、プラグインの自動インストールではありません。

**通知が必ず指定時刻に出ますか？** いいえ。AI利用時間と表示条件で決まります。再通知の45分は期限で、その時点で前面アプリなどの条件が合わなければ待機します。この通知はアプリ独自の小さなウィンドウで、macOS標準通知センターの履歴にはなりません。

**更新後、再びカメラを許可する必要がありますか？** ローカル署名の変更で再確認される場合があります。まずシステム設定のプライバシーとセキュリティ → カメラを確認します。通常利用のためにアクセシビリティを新たに許可しないでください。

**記録はどこですか？** 標準ビルドは`~/Library/Application Support/Squat/workout.sqlite`です。個人用の引継ぎ版は`~/Library/Application Support/Squat for Mac/Profiles/<UUID>/workout.sqlite`を使う場合があります。設定と利用時間は別途macOSの環境設定に保存します。詳しくは[PRIVACY.md](../PRIVACY.md)。

**更新・バックアップは？** アプリを正常に終了してから、該当の記録フォルダと環境設定をバックアップしてください。データはアプリ本体と別にあります。配布版から個人用プロファイルへの自動移行や、クラウド同期の画面はありません。複数の版を同じ記録へ同時に接続しないでください。

**問い合わせは？** 設定のContact usから[Google Form](https://forms.gle/1ZvABbbDHBRJsd529)を開きます。アプリから記録や診断情報を自動送信しません。公開の場に個人の記録・会話・カメラ映像を載せないでください。
