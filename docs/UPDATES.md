# GitHubからダウンロードして置き換える

Squat for Macは更新を自動配信しません。利用者がGitHub Releasesから新版のZIPをダウンロードして起動し、確認画面の **置き換える** を押した場合だけApplicationsの旧版を差し替えます。

## 利用者の記録

更新で置き換わるのは`Squat for Mac.app`です。標準版の運動記録は`~/Library/Application Support/Squat/`、設定と利用時間は`local.thinkandmove.mvp`のmacOS環境設定にあり、アプリ本体には入っていません。同じmacOSユーザーであれば更新後も引き継がれます。旧確認版が個別の保存プロファイルを使っている場合は、初回置換時にその識別子だけをmacOS環境設定へ移し、既存の記録と設定を引き続き参照します。記録そのものをアプリ内へコピーする処理ではありません。

新版は旧版を終了し、同じApplicationsフォルダ内に段階コピーを作成します。コピーと署名を確認してから旧版を一時バックアップして置き換え、もう一度検証して新版を開きます。最終検証に失敗した場合は旧版へ戻します。macOSの権限でApplicationsへ書き込めない場合は旧版を変更せず、Finderでの手動移動を案内します。

## リリースごとの手順

1. `Info.plist`の表示バージョンとビルド番号を増やします。
2. 変更点と既知の制限をリリースノートへ記録します。
3. `./scripts/check.sh`と`./scripts/check-integrations.sh`を通します。
4. `./scripts/package.sh`を実行します。ZIPとSHA256が`dist/`に生成されます。
5. アーカイブ内容、同じバージョンの上書きでないこと、個人データを含まないことを確認します。
6. 所有者が公開を判断した後だけ、`v<version>`のGitHub ReleaseへZIPとSHA256を添付します。
7. すでにインストールされた一つ前の版がある状態で、配布ZIPの新版を起動し、確認画面、置換、再起動、記録・設定の保持を実機で確認します。
