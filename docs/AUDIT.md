# 0.9.0 監査・検証結果

確認日：2026-10-19。非公開での日常利用と、一般配布の準備を区別した記録です。「欠陥が絶対にない」という保証ではありません。

## 今回の結果

- セキュリティの標準プロファイルによるソース監査：**15領域・37件のソース確認。確定した脆弱性0件、残った具体的な脆弱性仮説0件。**
- 4つの事前調査、3回の調査・再確認の波、その都度の範囲確認と別担当の最終確認を実施。以前の同等の監査台帳はなく、今回が最初の台帳です。
- 機械可読の範囲台帳・結果の検証は両方PASS。監査資料とソースのハッシュ一覧は所有者がローカルに保管しています。
- 個別の機能チェック、実際のメニューを使う表示試験、ビルド・署名整合性・配布ZIPの検査を実施しました。これらはセキュリティ上の攻撃耐性を実証する試験とは別です。
- デスクトップへの個人用配置では既存の保存先と設定を維持。一般用ZIPは別に作成し、個人の記録・設定・プロファイルを含めていません。

## セキュリティ監査の範囲と限界

対象は当時のSwift実行経路、カメラ処理、履歴・移行、時間計測、通知状態、共有とURL、当時存在した任意のローカル連携、同梱素材・実行ファイル、ビルド・配布、開発用のダウンロード統計です。旧アクセシビリティ監視が通常の起動経路で無効であることも確認しました。

確認したソースと素材のスナップショット識別子：

`sha256:a27c66075f930630c3e6b3457429e432f32b2a7d180863567f06ce7f247b4f5f`

**セキュリティ監査はソース確認です。** 総ディスク使用量、子プロセスの資源制限、ホスト設定の隔離を同時に強制できる検証環境がなかったため、監査対象コードを使った動的な攻撃試験は実施していません。実在の会話、アカウント、稼働中の外部サービス、本人のDBへの攻撃的な検証も行っていません。第三者による認証やAppleの審査結果ではありません。

この監査時点に存在したローカル連携は、0.9.3の現在のソースから削除されています。現在もApp Sandboxによる配布ではありません。

## 配布前に説明しておくこと

- ウィンドウを閉じてもメニューバーで動作します。「終了」すると計測が止まります。ログイン時の自動起動はありません。
- AI時間は選択したMacアプリの前面利用です。ブラウザ版や背面での生成時間、送信数、トークン数ではありません。
- カメラ映像は保存・アップロードしません。通常利用にはアクセシビリティ・画面収録・マイク権限は不要です。
- 通知は独自のカードで、通知センターや集中モードと自動連携しません。
- 通知は前面でのAI利用時間を基準にします。送信イベントや回答完了は検出しません。
- 共有画像・クリップボード・外部フォーム／SNSを選ぶ操作では、その宛先に情報が渡ります。画像は共有終了直後に必ず削除される設計ではありません。
- 現在のカウントは顔位置の上下移動です。スクワットの正しいフォームを保証しません。
- 配布版のDeveloper ID署名・公証、コードライセンス、対象ハードウェア、共有中の終了、問い合わせの返信方法は未完了です。

共有の初期URLを公開リポジトリへ設定し、旧デモURLだけを移行します。独自URL・記録・保存先は保持します。外部リンク・保存・導入状態36件、保存先11件、設定・画面制御60件のチェックが通過しました。配布ZIP60ファイルとソース・過去のGit履歴を検査し、個人記録・プロファイル指定・認証情報を検出しませんでした。

## 0.9.3 ダウンロード後の置換

利用者がGitHub Releasesから新版をダウンロードして起動し、確認した場合だけApplicationsの旧版を置き換えます。アプリはダウンロードや強制更新を行いません。新旧バージョン判定、通常ディレクトリだけを対象とする検査、段階コピー、最終検証、失敗時の旧版復元を実装し、一時フォルダで自動検証しています。記録と設定はアプリ本体とは別の保存先にあります。旧確認版の個別保存プロファイルは、署名済み新版を改変せず、識別子だけをmacOS環境設定へ移して引き継ぎます。

2026-10-21に同一Mac上で、Applicationsの0.9.1から0.9.3候補への確認画面、旧版終了、置換、署名検証、新版起動、個別保存プロファイルの設定移行、記録保持を確認しました。置換前後の履歴件数は一致し、SQLiteの整合性検査も通過しています。これは0.9.0時点の全面監査をやり直したという意味ではありません。配布ZIPを展開した状態、Applicationsへ書き込めない権限分岐、別MacとGatekeeperは今後の受入項目です。
