# 0.9.0 監査・検証結果

確認日：2026-10-19。非公開での日常利用と、一般配布の準備を区別した記録です。「欠陥が絶対にない」という保証ではありません。

## 今回の結果

- セキュリティの標準プロファイルによるソース監査：**15領域・37件のソース確認。確定した脆弱性0件、残った具体的な脆弱性仮説0件。**
- 4つの事前調査、3回の調査・再確認の波、その都度の範囲確認と別担当の最終確認を実施。以前の同等の監査台帳はなく、今回が最初の台帳です。
- 機械可読の範囲台帳・結果の検証は両方PASS。監査資料とソースのハッシュ一覧は所有者がローカルに保管しています。
- 個別の機能チェック、実際のメニューを使う表示試験、ビルド・署名整合性・配布ZIPの検査を実施しました。これらはセキュリティ上の攻撃耐性を実証する試験とは別です。
- デスクトップへの個人用配置では既存の保存先と設定を維持。一般用ZIPは別に作成し、個人の記録・設定・プロファイルを含めていません。

## セキュリティ監査の範囲と限界

対象はSwiftの実行経路、カメラ処理、履歴・移行、時間計測、通知状態、共有とURL、ローカルIPC、任意のhook、プラグイン検出、同梱素材・実行ファイル、ビルド・配布、開発用のダウンロード統計です。旧アクセシビリティ監視が通常の起動経路で無効であることも確認しました。

確認したソースと素材のスナップショット識別子：

`sha256:a27c66075f930630c3e6b3457429e432f32b2a7d180863567f06ce7f247b4f5f`

**セキュリティ監査はソース確認です。** 総ディスク使用量、子プロセスの資源制限、ホスト設定の隔離を同時に強制できる検証環境がなかったため、監査対象コードを使った動的な攻撃試験は実施していません。実在の会話、アカウント、稼働中の外部サービス、本人のDBへの攻撃的な検証も行っていません。第三者による認証やAppleの審査結果ではありません。

ローカルIPCには同一ユーザー・トークン・サイズ・型の検査があり、通知発火には世代・鮮度・前面アプリ等の条件があります。同じMacユーザーとして動く悪意あるソフトからの完全な隔離を意味しません。App Sandboxによる配布でもありません。

## 配布前に説明しておくこと

- ウィンドウを閉じてもメニューバーで動作します。「終了」すると計測が止まります。ログイン時の自動起動はありません。
- AI時間は選択したMacアプリの前面利用です。ブラウザ版や背面での生成時間、送信数、トークン数ではありません。
- カメラ映像は保存・アップロードしません。通常利用にはアクセシビリティ・画面収録・マイク権限は不要です。
- 通知は独自のカードで、通知センターや集中モードと自動連携しません。
- 時間方式はプラグインなしで使えます。送信連携は実験段階で、通常版向けの導入案内には制限を明記しています。
- 共有画像・クリップボード・外部フォーム／SNSを選ぶ操作では、その宛先に情報が渡ります。画像は共有終了直後に必ず削除される設計ではありません。
- 現在のカウントは顔位置の上下移動です。スクワットの正しいフォームを保証しません。
- 配布版の署名・公証、コードライセンス、対象ハードウェア、共有中の終了、ヘルパー再生成、問い合わせの返信方法は未完了です。
